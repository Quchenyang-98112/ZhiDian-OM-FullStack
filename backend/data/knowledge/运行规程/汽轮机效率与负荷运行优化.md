# 汽轮机效率与负荷运行优化

## 文档属性

- 文档类型：运行规程摘要
- 所属系统：汽轮机系统
- 适用场景：1号超临界燃煤机组、2号超临界燃煤机组
- 资料性质：公开资料整理 + 火电厂仿真测试规则，不替代现场规程

## 核心规则

1. 在满足最小技术出力、主蒸汽温度、主蒸汽压力、排汽温度和轴承振动安全边界的前提下，优先选择高效率负荷区间。
2. 设备无明显故障但供电煤耗持续偏高时，先生成运行参数调整方案，再判断是否需要维护时机优化。
3. 参数调整必须记录调整前后负荷、煤耗、供电量、碳排放和安全裕度，便于决策 Agent 复核。
4. 当轴承振动、润滑油温或排汽温度呈持续上升趋势时，不得仅以降负荷替代诊断，应进入诊断 Agent 证据链。

## 可检索证据

- 当前负荷率与设计高效区间的偏差
- 单位发电煤耗和小时碳排放
- 汽轮机高压缸轴承振动 RMS 的 30 分钟历史趋势
- 主蒸汽参数、凝汽器真空度和润滑油温的同步变化
