# 汽轮机轴承振动仿真案例

## 案例标识

- 案例编号：SIM-TURBINE-2026-001
- 机组：2号超临界燃煤机组
- 设备：汽轮机高压缸
- 测点：轴承振动 RMS
- 数据性质：仿真数据，仅用于联调和演示

## 证据摘要

过去 30 分钟内，轴承振动由 5.8 mm/s 上升至 8.6 mm/s，较稳定基线升高约 42%。同步检索到汽轮机轴承振动规程、润滑案例和计划检修策略，初步判断为轻度退化伴随润滑状态变化的候选原因。

## Agent 输出约定

监控 Agent 输出异常事件和时间窗口；诊断 Agent 输出候选原因、证据来源和置信度；决策 Agent 输出运行参数调整、维护时机调整、碳感知运行三类方案的多目标比较。
