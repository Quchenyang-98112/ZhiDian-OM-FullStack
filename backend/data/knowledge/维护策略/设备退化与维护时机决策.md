# 设备退化与维护时机决策

## 文档属性

- 文档类型：维护策略卡
- 所属系统：汽轮机系统
- 资料性质：项目仿真知识文档

## 三方案比较

当汽轮机高压缸轴承出现轻度退化但尚未达到立即停机条件时，诊断 Agent 不直接输出“马上维修”，而是把以下方案交给决策 Agent：

- 方案 A：继续运行，增加振动、润滑油温和回油压力采样频率。
- 方案 B：立即检修，安全风险低但会产生停机损失。
- 方案 C：安排下一个计划检修窗口更换轴承，兼顾风险、附加能耗和运维成本。

## 比较维度

安全风险优先，其次比较故障持续期间的附加能耗、碳排放、停机损失、维护成本和备件可用性。证据不足时，输出补充监测任务，不生成不可逆执行动作。

## 测试阈值

- 轴承振动 RMS 低于 5.0 mm/s：正常观察
- 5.0–7.0 mm/s：关注，补充证据
- 7.0–10.0 mm/s：预警，进入维护时机比较
- 高于 10.0 mm/s 或快速上升：高风险，必须人工审批
