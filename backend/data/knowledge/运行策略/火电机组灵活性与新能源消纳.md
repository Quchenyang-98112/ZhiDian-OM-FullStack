# 火电机组灵活性与新能源消纳

## 文档属性

- 文档类型：运行策略
- 所属系统：电气系统 / 锅炉系统 / 汽轮机系统
- 资料性质：公开技术报告摘要 + 仿真策略

## 策略逻辑

平台将新能源消纳作为决策 Agent 的独立场景：

1. 中午光伏富余时，比较“正常充放电、富余新能源时充电、提高低谷消纳”三类方案。
2. 傍晚净负荷爬坡时，检查火电机组最小技术出力、升降负荷速率、储能 SOC 和设备健康度。
3. 当设备健康度下降或高风险操作出现时，限制充放电倍率并转人工审批。
4. 方案输出必须同时展示消纳提升、新能源弃电减少、碳排放变化和安全风险。

## 建议指标

- 新能源可用出力 / 实际消纳出力
- 弃新能源电量
- 火电调节空间
- 储能 SOC 与预计充放电功率
- 单位电量碳排放和日减排量
