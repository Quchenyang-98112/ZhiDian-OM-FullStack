# 燃煤机组碳排放核算与排放因子

## 文档属性

- 文档类型：碳核算方法卡
- 所属系统：通用 / 锅炉系统
- 资料性质：公开排放因子资料整理 + 项目演示计算约定

## 演示计算链

平台在演示模式下采用统一、可追溯的计算链：

```text
基准电量 E_base = 时间窗口平均出力 P_actual × 时间 t
基准排放 C_base = E_base × 排放因子 EF_grid
故障附加能耗 E_fault = E_base × (1 + k_f)
措施后能耗 E_after = E_current × (1 - η)
减排量 ΔC = C_current - C_after
减排率 R_carbon = ΔC / C_current
```

其中 `k_f` 表示故障或退化导致的附加能耗率，`η` 表示措施带来的能效改善率。演示数据会在结果中显示时间窗口、排放因子和假设，避免把估算值误读为碳盘查结论。

## 运行规则

- 设备正常但能效偏低：优先比较运行参数调整前后的单位能耗和碳排放。
- 设备轻度退化：将继续运行、立即维修、计划窗口维修放入同一比较表。
- 新能源/储能场景：同时考虑新能源富余、电网排放因子、储能 SOC、设备健康度和安全边界。
- 低置信度或高风险动作必须进入人工审批。
